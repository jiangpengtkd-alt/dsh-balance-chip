本页 CSS 由 tools/gen-preview.mjs 从 lib/client.js 求值生成，与实机同一份定义。
原厂 StatsPills 的真实 CSS（.iq1doa_*）也内置其中，用于并排对照。

① 实机排布：上下文圆圈 + 余额胶囊

42%

三段各带标签，避免混淆，按变化速度由慢到快排列：总余额（充值余额 + 赠金余额，快照）· 会话累计（本会话建立至今的累计）· 本轮消耗（这一句话从发问到此刻的合计，跳动最明显）。
三个圆点同色，按总余额分档：≥100 绿 · 20–99 黄 · 1–19 红 · 其他灰。
号码段前是 5px 状态块，后两段标签前是 5px 小方点（对齐原生胶囊"每段都有图标"的节奏）。
数值用等宽数字，且不预留最小宽度 —— 预留会让标签与数字之间出现空白。 三段始终占位：本轮还算不出来时显示 —，不整段省略 —— 避免数字左右横移（见下方 ④）。

② 与原厂胶囊并排（分隔点 / 字号 / 间距一致性）

两边的分隔点应大小、亮度、间距一致 —— 都用 var(--dsw-alias-separator-primary) 且 margin:0 6px，字号都用同一个 calc 表达式。

④ 三段始终占位（无值显示 "—"）、余额分档、异常状态

正常三态：圆点颜色按余额分档（≥100 绿 · 20–99 黄 · 1–19 红 · 其他灰）。

关键：位置必须稳定。下面是同一个会话从「刚打开」到「本轮跑起来」的连续状态 —— 三段始终存在，只是无值时显示 —。数字不会因某段出现/消失而左右横移。
